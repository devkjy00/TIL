- 엔진에 의한 런타임 이전 변수 실행(호이스팅)은 전역변수만 해당된다(함수x)
	- 호이스팅은 스코프 별로 동작함(해당 스코프 실행시)

- 전역객체는
	- 클라이언트 사이드(브라우저) window
	- 서버 사이드(node.js) global
	- window, self, this, frames, global => ES11 이후 globalThis로 통일

- 전역 변수는 스코프 체인 종점에 존재 == 검색 속도가 가장 느리다
- ***네임스페이스 오염***
	- 파일이 달라도 하나의 전역 변수를 공유하는 문제.. 일반적인 이름은 쓰면 안되겠군

#### 전역변수 사용 억제
- 즉시 실행 함수
	- 내부 모든 변수를 지역변수로(var 함수도)

- 네임스페이스 객체
	- 변수가 아니라 객체를 전역으로..

- 모듈 패턴
	- 접근 제한자를 쓰는 것처럼 공개할 값과 아닌 값을 분리(private, public 느낌)
	- 즉시 실행함수의 return 값을 객체(public 역할)로 반환하는 방식으로 구현

#### ES6 모듈
- 파일 자체의 독자적 모듈 스코프를 사용 -> 전역변수를 쓸수 없다
- 모던 브라우저에서 ES6를 사용가능(IE등 구형 브라우저에서 동작 x)
	- `<script type="module" src="app.mjs">` 이렇게 쓰면 됨
	- 확장자로 mjs를 권장
- 하지만 WebPack 등의 모듈 번들러를 사용하는 것이 일반적이다
