
#### 스코프(유효범위)
- 엑시컬 환경(exical environment) : 실행되는 코드 주변에 어떤 코드가 있는지에 대한 환경
- var 키워드는 같은 스코프에서 중복 선언이 가능해서 부작용이 발생한다
	- let, const를 사용하자

#### 스코프 체인
스코프 체인 : 실행 컨텍스트의 렉시컬 환경을 단방향으로 연결한것..
- **변수를 찾기 위해 내부 스코프에서 외부 스코프 방향으로 차례대로 따라가는 길**
	- 고로 상위 스코프에 있는건 제약이 없으면 다 쓸 수 있다네?

#### 함수 레벨 스코프
- var 키워드
	- 다른 언어(블록레벨스코프)와 다르게 함수에 의해서만 지역 스코프가 생성된다 (for/if/while/try x)
- let, const
	- 블록 레벨 스코프

#### 렉시컬 스코프
- 렉시컬 스코프/정적 스코프 : 정의 된 위치를 기준으로 상위 스코프 결정, 대부분 언어의 방식
	- 동적 스코프(dynamic scope) : 호출 시점 기준으로 상위 스코프 결정
